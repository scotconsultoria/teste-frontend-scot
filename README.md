# Teste Técnico – Desenvolvedor Front-end

## Objetivo
Avaliar os conhecimentos do candidato em HTML, CSS, responsividade, organização de código e boas práticas de desenvolvimento front-end.

---

## Instruções

### 1. Tela de Login
- Crie uma tela de login com:
  - Validação de e-mail
  - Validação de senha contendo:
    - No mínimo 8 caracteres
    - Letras maiúsculas e minúsculas
    - Números
    - Caracteres especiais

> A validação pode ser feita apenas no front-end.

---

### 2. Tela Principal
Após o login, exiba uma tela principal no estilo de **portal de notícias**, contendo:
- Menu horizontal
- Rodapé
- Pelo menos uma imagem
- Pelo menos um vídeo (pode ser embed)
- Exibição do e-mail informado no login

---

### 3. Layout e Responsividade
- Desenvolva a aplicação de forma **responsiva**
- Utilize **HTML5 e CSS3**
- É permitido o uso de pré-processadores como **SASS, LESS ou Stylus**

---

### 4. Código
- O código será avaliado mesmo que o projeto não esteja 100% completo
- Priorize:
  - HTML semântico
  - Organização
  - Legibilidade
  - Boas práticas

---

## O que esperamos
- HTML5
- CSS3
- JavaScript (opcional)
- Um passo a passo explicando como rodar o projeto

---

## Diferenciais
- Organização de pastas
- Boa experiência do usuário (UX)

---

## Observações
- É permitido usar qualquer editor de código
- É permitido consultar a internet durante o teste

---

## Entrega

Envie sua solução em um arquivo **.zip** para **at@scotconsultoria.com.br** em até **10 dias corridos** após o recebimento do teste.

- **Assunto do e-mail:** `Teste Front-end – Seu Nome`
- **Nome do arquivo:** `teste-frontend-seu-nome.zip`

> ⚠️ **Não** faça fork nem Pull Request deste repositório.

### O .zip deve conter
- Todo o código-fonte do projeto
- Um arquivo **`README.md` na raiz** com o passo a passo para executar o projeto, incluindo:
  - Pré-requisitos e versões utilizadas
  - Instalação de dependências
  - Configuração necessária
  - Comando(s) para executar (ex.: `abrir o index.html no navegador`)

### Não inclua no .zip
- Pastas de dependências (`node_modules`, `vendor`, `venv`, `.venv`, `__pycache__`)
- Arquivos com senhas reais (`.env`); envie um `.env.example` no lugar

> Se o arquivo passar de 20 MB, envie um link de download (Google Drive, WeTransfer etc.).
